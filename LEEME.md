# Closeby

Lejos en el mapa, cerca en todo. App para parejas a distancia: finanzas en varias monedas, ahorro para viajes y calendario compartido.

- `index.html` — la app
- `closeby-supabase.js` — inicio de sesión, código de pareja y conexión con Supabase
- `sw.js`, `manifest.webmanifest`, `icons/` — para instalarla en el celular

La base de datos se crea con `supabase.sql` (se pega una vez en Supabase → SQL Editor).
